Stars
-----
Contains all stars with apparent magnitude of 6 or less. Magnitude 6.5 (search parameter: Vmag < 6.5) is the dimmest star that can be observed with the naked eye under optimal conditions.

Parameters:
 - Right Ascension
 - Declination
 - Proper Motion in RA
 - Proper Motion in Dec
 - Radial Velocity
 - Heliocentric Parallax
 - Visible Light Magnitude
 - Red, Green, Blue values based on spectral type

Data is obtained from SIMBAD: https://simbad.u-strasbg.fr/simbad/ using the following steps:
1) Configure the output formats on: https://simbad.cds.unistra.fr/simbad/sim-fout
   - Output Format = ASCII (;-separator for spreadsheet)
   - Check the "file output" box
   - Max. # of objects = 20000
